# 📈 MOEX Portfolio Optimizer (Markowitz Model)
English version -> [here](README-EN.md)

Интерактивное веб-приложение для оптимизации инвестиционного портфеля на основе акций Московской Биржи. Проект реализует **Современную портфельную теорию** Гарри Марковица для поиска портфеля с минимальным риском.

## ✨ Основные возможности
* **Автоматизация данных**: Загрузка котировок напрямую с MOEX через API ISS.
* **Smart Risk-Free Rate**: Динамическое получение актуальной ключевой ставки с официального сайта ЦБ РФ с помощью веб-скрапинга.
* **Алгоритмическая оптимизация**: Использование метода `SLSQP` для минимизации волатильности портфеля при заданных ограничениях.
* **Интерактивный интерфейс**: Построен на Streamlit, позволяет менять состав тикеров, бюджет и видеть результат мгновенно.
* **Чистая визуализация**: Автоматическая фильтрация активов с околонулевым весом для удобства анализа.

## 📐 Как это работает
1. Программа собирает исторические цены закрытия по выбранным тикерам.
2. Рассчитывается логарифмическая доходность, средняя доходность и ковариационная матрица активов.
3. Программа заходит на сайт cbr.ru и извлекает текущую ключевую ставку в качестве безрисковой доходности ($R_f$).
4. Решается задача минимизации функции риска (волатильности):
   $$\sigma_p = \sqrt{w^T \Sigma w}$$
   при условии $\sum w_i = 1$.

## 🚀 Запуск проекта
1. Клонируйте репозиторий:
   git clone [https://github.com/Maradelli/Portfolio-optimization.git](https://github.com/Maradelli/Portfolio-optimization.git)
2. Установите зависимости:
   pip install -r requirements.txt
3. Запустите приложение:
   streamlit run App.py
