# Оптимизация инвестиционного портфеля по Марковицу (MOEX).

Цель проекта — разработать алгоритм, который автоматически подбирает оптимальные доли акций в портфеле для минимизации риска при заданном уровне доходности. Проект ориентирован на российский фондовый рынок и использует данные Московской Биржи (MOEX).

## Технологический стек
1) Python 3.13
2) Pandas
3) Numpy
4) SciPy (Optimize)
5) Matplotlib
6) Seaborn
7) Requests
8) APIMOEX
9) Streamlit

## Математический аппарат

1) Расчёт логарифмической доходности:
$r_t = ln(\frac{P_t}{P_{t-1}})$

2) Матрица ковариации: оценка взаимосвязи между активами для снижения общего риска портфеля за счёт диверсификации.
3) Оптимизация: решение задачи минимизации волатильности портфеля:
$\sigma_p = \sqrt{w^T \sum w}$ при условии $\sum w_i = 1$

## Результаты
- Реализован стабильный сбор данных с Московской Биржи
- Построена модель, распределяющая капитал между активами
- Визуализированы итоговые веса в процентах и денежном эквиваленте
